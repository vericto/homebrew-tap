# Vericto Homebrew tap

[Homebrew](https://brew.sh) formulae for the
[Vericto CLI](https://github.com/vericto/vericto-cli) (`vericto`), which checks
SQL against your Vericto workspace's security rules before it runs. Supported:
macOS (Apple silicon and Intel) and Linux (arm64 and x86_64).

## Install

```bash
brew install vericto/tap/vericto
vericto --version
```

Naming the tap in the command (`vericto/tap/vericto`) taps this repository and
tells Homebrew to trust this formula. Homebrew only loads formulae from
third-party taps that you have trusted
([Tap Trust](https://docs.brew.sh/Tap-Trust)); if you tapped first with
`brew tap vericto/tap`, trust the formula with
`brew trust --formula vericto/tap/vericto`.

If `vericto` is already installed from npm (`npm install -g
@vericto/vericto-cli`), remove that one first with
`npm uninstall -g @vericto/vericto-cli`: with a Homebrew-managed Node both put
a `vericto` in the same `bin` directory, and `brew` will not overwrite it.

## Upgrade

```bash
brew update
brew upgrade vericto
```

A new formula is published here by the CLI's release workflow for every
release.

## Uninstall

```bash
brew uninstall vericto
brew untap vericto/tap        # optional: remove the tap as well
```

`brew uninstall` leaves your login and settings in `~/.config/vericto/` in
place (or `$XDG_CONFIG_HOME/vericto/`); delete that directory to remove them.

## How the download is verified

- **SHA-256 in the formula.** `Formula/vericto.rb` points at the release
  archives on [GitHub Releases](https://github.com/vericto/vericto-cli/releases)
  (on Linux, the static musl builds) and pins each one by its SHA-256, the
  value in the release's `sha256.sum`. Homebrew refuses to install an archive
  that does not match. The release workflow checks every pinned SHA-256
  against `sha256.sum` before it pushes the formula here.
- **Build attestation.** Every release archive carries a Sigstore-backed GitHub
  attestation that ties it to the vericto/vericto-cli repository, its release
  workflow and the commit it was built from. To check the archive Homebrew
  downloaded (needs the [GitHub CLI](https://cli.github.com) 2.49 or later):

  ```bash
  gh attestation verify "$(brew --cache vericto/tap/vericto)" --repo vericto/vericto-cli
  ```

## How this tap is maintained

The formula is generated by [cargo-dist](https://opensource.axo.dev/cargo-dist/)
in the CLI's release workflow and pushed to `main` here by its
`homebrew-publish` job, which needs approval of the CLI repository's `prod`
environment. Do not edit `Formula/vericto.rb` by hand: the next release
replaces it. Fixes to the formula belong in
[vericto/vericto-cli](https://github.com/vericto/vericto-cli)
(`dist-workspace.toml` and `.github/workflows/homebrew-publish.yml`).

[`tests`](.github/workflows/tests.yml) audits, installs and tests each formula
(`brew audit --strict --online`, `brew install`, `brew test`) on every push and
pull request: Linux x86_64 and arm64 run always; macOS arm64 and x86_64 run
when started by hand while this repository is private, and on every push and
pull request once it is public.
